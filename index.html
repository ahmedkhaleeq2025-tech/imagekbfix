Frequently asked questions

Is ImageKBFix free?

The tools currently available on this site are free to use and do not require registration.

Are my files uploaded to a server?

The implemented tools process selected files in your browser and do not intentionally upload them to an ImageKBFix server. PDF processing libraries are fetched from third-party CDNs.

Which formats are supported?

The image tools support JPG/JPEG, PNG, and WebP. The PDF workspace supports the PDF operations shown on this page.

Can I use ImageKBFix on mobile?

The interface adapts to mobile screens. Processing capacity depends on the device and browser memory.

Can image compression guarantee an exact file size?

No. The target is a best-effort limit; the output size depends on the image and browser encoder.

Is there a file size limit?

The image upload tool accepts files up to 25 MB and images up to 40 megapixels. PDF processing is limited by available browser memory.

Files are processed in your browser and are not intentionally uploaded by these tools. PDF tools load their processing libraries from third-party CDNs.
